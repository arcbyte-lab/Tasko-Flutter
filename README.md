# Tasko (Flutter)

Team and personal tasks. The thinking lives in arcbyte (`ideas/tasko/`); this
repo is the code.

Right now it is the home screen only (calendar heatmap, workspace and project
tabs, the task list and its checkbox), running on `FakeTasksApi` seed data.
The Laravel API comes later: swap the API in `lib/main.dart`.

```
flutter run
flutter analyze && flutter test
```
